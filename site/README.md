# askpolymath.com static site

The public showcase and the run-your-own guide, published free on GitHub Pages
by `.github/workflows/pages.yml`. Plain HTML and CSS, no build step:
`index.html` (what Polymath is, the film, every tool and feature, real results,
costs) and `guide.html` (running your own copy on your own Meta key, including
concept art, Zenodo publishing and sign-in). Media in `media/` are web-sized
copies of the live-run clips and screenshots in `docs/demo/`.

Preview locally: `python3 -m http.server -d site 8000`, then open
http://localhost:8000.
