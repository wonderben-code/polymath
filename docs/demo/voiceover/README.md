## Script

1+2. Science has thousands of fields. Answers to one problem often hide in unrelated fields. Polymath finds them. Ask anything, and Meta's Muse Spark searches all of open science.

3. It has five tools, for any question, problem or invention. First, Ask. Muse Spark reads real papers and answers with numbered claims, each showing the exact passage it came from, and how certain it is.

4. Second, Solve. Give it any problem you can imagine. It checks whether science already has the answer. If it doesn't, it invents a new solution, borrowing ideas from other fields and combining them into something new, and tells you honestly where it's still weak.

5. Third, Converge, for exploring. Give it any topic you're curious about. Muse Spark picks twelve far-apart fields and asks what each one knows about it. It checks every link against real research, and throws out any that don't hold up. What survives comes together as a new idea, or a new combination of ideas, that no single field could see.

6. Fourth, Frontier. Give it any unsolved problem, however sci-fi. It maps the fields closest to it, works out the gaps between today and that goal, hunts other sciences for answers, and breaks the hardest gaps into steps. Here, for example, a six-step plan for a space elevator, created in just nineteen minutes.

7. Fifth, Studio. It invents anything you can describe or dream of. Give it a brief. Muse Spark searches the literature for mechanisms that already work. Here, for example, a humpback's fins, an owl's feathers and a seal's swimming stroke are combined into a new submarine that glides in a sawtooth. Meta's image model paints the concept art. Then it engineers the design with real numbers, tests it against your requirements, and lists what still has to be invented. Every source is real, and it says what it cannot prove. If you can dream it, Studio can start inventing it.

8. Any question, problem or invention. Try it free at askpolymath.com, and publish anything you discover to Zenodo. Polymath: discoveries across all of science, powered by Meta.
